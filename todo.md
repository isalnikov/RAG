### 📌 Итоговый стек и ключевые решения

**1. Среда исполнения**
- **Java 17 + Spring Boot 3.5**, все работает локально на вашем компьютере.
- В качестве базы — **SQLite** с расширением `sqlite-vec` для быстрого векторного поиска прямо внутри процесса.
- Для взаимодействия с LLM и embedding-моделями используем **Ollama** (легко установить, работает без GPU, предоставляет OpenAI-совместимый API).

**2. Модели (только открытые, без GPU)**
- **Эмбеддинги**: `multilingual-e5-small` (118M параметров) — специально обучена поддерживать русский язык и показывает хорошие результаты на поиске по разнородному контенту. В Ollama она доступна как `jeffh/multilingual-e5-small` (или можно использовать официальный `multilingual-e5`). Это лучший баланс скорости и качества для CPU.
- **Генеративная LLM**: одна из русскоязычных моделей, оптимизированных под CPU:
  - `saiga_mistral_7b` (GGUF, квант Q4_K_M) — отлично понимает русский, писалась для инструкций.
  - `qwen2:7b-instruct` (также поддерживает русский).
  - `openchat` или `zephyr` — если нужен более легкий вариант.  
  Любая из них запускается через Ollama командой `ollama pull <имя>` и работает на CPU.

**3. Обработка и хранение документов**
- Извлечение текста из PDF: **Apache PDFBox**.
- Предобработка: удаление колонтитулов, лишних переносов, дедубликация по MD5-хешу.
- Чанкинг: **семантический**, с группировкой предложений на основе косинусного сходства их эмбеддингов. Это позволит сохранять логически цельные куски кода и текста, не разрывая важные конструкции.
  - Целевой размер чанка: около **400–500 токенов** (меньше для CPU-эмбеддингов — компромисс между качеством и скоростью).
  - Перекрытие: **50 токенов** (примерно 10%).
- Хранение векторов: в SQLite таблице `chunks` с колонкой `embedding BLOB` и индексацией через `sqlite-vec` виртуальную таблицу для ANN-поиска по косинусному расстоянию.

**4. Поиск и генерация ответа**
- Пользовательский вопрос передается в embedding-модель, преобразуется в вектор.
- `sqlite-vec` находит 5–10 самых близких чанков.
- Эти чанки подаются как контекст в локальную LLM вместе с вопросом. LLM генерирует финальный ответ на русском языке.
- Весь процесс внутри одного приложения без внешних сервисов.
